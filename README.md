A Model Context Protocol (MCP) server that provides AI image generation and editing capabilities using Google's Gemini image generation API. Generate stunning images, edit existing ones, and iterate on your creations with simple text prompts.

## ✨ Features

- 🎨 **Generate Images**: Create new images from text descriptions
- ✏️ **Edit Images**: Modify existing images with text prompts
- 🔄 **Iterative Editing**: Continue editing the last generated/edited image
- 🖼️ **Multiple Reference Images**: Use reference images for style transfer and guidance
- 🌍 **Cross-Platform**: Smart file paths for Windows, macOS, and Linux
- 🔧 **Easy Setup**: Simple configuration with API key
- 📁 **Auto File Management**: Automatic image saving with organized naming

## ⚙️ Configuration Priority

The MCP server loads your API key in the following priority order:

1. **🥇 MCP Configuration Environment Variables** (Highest Priority)
   - Set in your `claude_desktop_config.json` or MCP client config
   - Most secure as it's contained within the MCP configuration
   - Example: `"env": { "GEMINI_API_KEY": "your-key" }`

2. **🥈 System Environment Variables**
   - Set in your shell/system environment
   - Example: `export GEMINI_API_KEY="your-key"`

3. **🥉 Local Configuration File** (Lowest Priority)
   - Created when using the `configure_gemini_token` tool
   - Stored as `.nano-banana-mcp/config.json` in the output directory
   - Automatically ignored by Git and NPM

**💡 Recommendation**: Use Method 1 (MCP config env variables) for the best security and convenience.

### Model Name

The image model name follows the same priority order as the API key:

1. **MCP/System Environment Variable**: `GEMINI_MODEL`
2. **Local Configuration File**: `modelName` in `.nano-banana-mcp/config.json` (set via `configure_gemini_token`)
3. **Default**: `gemini-nano-banana-2.1`

If `GEMINI_MODEL` is not set anywhere, the server uses `gemini-nano-banana-2.1`.

Use the `list_models` tool to fetch the current list of model names, descriptions, and capabilities from Google's API.

## 📁 File Storage

All server output (images and the configuration file) is stored under a `.nano-banana-mcp` directory:

- **Windows**: `%USERPROFILE%\\Documents\\.nano-banana-mcp\\`
- **macOS/Linux**: `./.nano-banana-mcp/` (in current directory)
- **System directories**: `~/.nano-banana-mcp/` (when run from system paths)

Within it:
- Images: `.nano-banana-mcp/images/`
- Configuration: `.nano-banana-mcp/config.json`

File naming convention:
- Generated images: `generated-[timestamp]-[id].png`
- Edited images: `edited-[timestamp]-[id].png`
